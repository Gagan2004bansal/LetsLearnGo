## Why GoLang?

1. Fast compilation and build time
2. Fast startup time
3. High performance and low resource usage
4. Simple and efficient concurrency model
5. Static typing with compiled binaries
6. Built for scalable backend services

## Goal

The goal of this repository is to learn Go by building practical backend systems and understanding how Go works with databases, caching, messaging, containers, and distributed services.
